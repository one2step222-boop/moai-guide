AI로 만들어봤습니다03

긴 영상을 쇼츠로 잘라주는 서비스는 보통 월 15달러부터 시작하고 분량 제한이 붙습니다. 같은 일을 무료 도구 두 개로 하는 순서입니다. 12분짜리 영상 기준으로 저희는 18초 걸렸습니다.

0. 준비물

세 가지가 필요합니다. 전부 무료입니다.

# 윈도우
winget install ffmpeg
pip install yt-dlp

파이썬은 3.7 이상이면 됩니다. 맥이면 brew install ffmpeg yt-dlp 입니다.

1. 도구 받기

claude-video 라는 오픈소스입니다. MIT 라이선스라 그냥 쓰면 됩니다.

git clone https://github.com/bradautomates/claude-video.git

2. 영상을 장면으로 가르기

영상 파일 경로만 주면 됩니다. 장면이 바뀌는 지점을 찾아 그 순간의 화면을 뽑아내고, 앞 장면과 거의 같은 그림은 알아서 버립니다.

python claude-video/skills/watch/scripts/watch.py "내영상.mp4" --no-whisper

저희는 11분 45초짜리 273MB 영상으로 2.4초가 걸렸고, 후보 96장 중 50장이 남았습니다. 화면마다 t=07:39 처럼 몇 분 몇 초인지 같이 나옵니다.

여기서 두 번 데었습니다. 하나, 질문을 명령어 뒤에 같이 적으면 unrecognized arguments 로 멈춥니다. 이 도구는 화면과 자막을 뽑아주는 데까지가 일이고, 질문은 그 결과를 받은 AI 에게 합니다. 둘, --no-whisper 를 빼면 음성을 받아쓰려고 API 키를 찾습니다. 말이 없는 영상이거나 화면만 필요하면 이 옵션을 붙이세요 — 돈이 안 듭니다.

3. 어디가 쇼츠감인지 묻기

2번이 뱉은 화면들을 AI 에게 그대로 주고 물어보면 됩니다. 클로드·챗지피티 아무거나 됩니다. 화면을 실제로 보기 때문에 말로 설명하지 않은 부분도 잡습니다.

이 화면들은 한 영상에서 뽑은 것입니다.
어디가 쇼츠로 쓸 만한지 시간대로 알려주세요.

저희가 받은 답은 07:39 였습니다. 순위 카드가 먼저 뜨고 화면 전환이 큰 구간이라는 이유까지 붙어 나왔습니다.

4. 그 구간만 세로로 잘라내기

ffmpeg 한 줄입니다. -ss 가 시작 시각, -t 가 길이입니다.

ffmpeg -ss 00:07:39 -t 30 -i "내영상.mp4" \
  -filter_complex "[0:v]crop=1080:1080:420:0,scale=1080:1080[fg];\
  [0:v]scale=1080:1920,boxblur=24[bg];[bg][fg]overlay=0:420" \
  -c:a copy "쇼츠.mp4"

가로 영상을 세로 화면에 넣는 방법입니다. 가운데를 잘라 위에 얹고, 빈 위아래는 같은 화면을 흐리게 깔아 채웁니다. 30초 클립 기준 15.5초 걸렸습니다.

가운데를 자르면 글씨가 잘립니다. 저희 첫 결과물은 게임 제목 왼쪽이 날아가서 "…ous Hacker Simulator" 가 됐습니다. crop=1080:1080:420:0 의 420 이 왼쪽에서 얼마나 떨어져서 자를지입니다. 자막이나 제목이 왼쪽에 몰려 있으면 이 숫자를 200 쯤으로 줄이세요.
